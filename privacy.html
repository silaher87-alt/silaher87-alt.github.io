Privacy Policy

This policy describes how the privately operated MMT Primary Backup utility is intended to use its owner's Google account for encrypted scanner-data backups. It is not a public consumer application.

1. What information may be accessed

With the owner's explicit Google OAuth consent, the utility may use Google Drive APIs to list folder entries, upload backup objects, verify or download uploaded objects and restore backup records. Although the application is designed to work only inside a dedicated MMT Primary backup folder, the OAuth scope selected may technically permit broader Drive access. Its folder restriction is a software control, not necessarily a Google-enforced folder-only permission.

The app does not need Gmail or Google Photos content and is not designed to inspect unrelated Drive documents.

2. How information is used

Google Drive access is used only to store, validate, recover and manage owner-authorised backups of non-trading scanner observations, source-only alert records, evidence logs, manifests and recovery records. It is not used to create trading transactions, profile users, serve advertisements or train AI models.

3. Storage and security

When deployed, the backup client is designed to encrypt backup contents and file names locally before uploading to Google Drive. Organisational category folders and some account or file metadata (such as timestamps, sizes and folder labels) may remain visible to Google. OAuth tokens and encryption secrets are intended to be stored in access-restricted server configuration, not on this public website or in the GitHub repository. Encryption and recovery must be tested before a live backup service is considered ready.

4. Sharing and service providers

The operator does not sell or share Google user data with advertisers or unrelated third parties. Google Drive provides the authorised storage, and rclone is used as a local backup-transfer client. This public informational website is hosted by GitHub Pages; it does not itself receive OAuth tokens or stored backups. Google and GitHub process service data under their respective policies.

5. Retention and deletion

Backups are intended to be retained until the owner explicitly deletes them according to the project's retention and recovery rules. Revoking OAuth access prevents future authorised Drive operations but does not automatically remove already uploaded backup files. The owner can review and delete those files from their Google Drive account.

6. Revoking access

The owner may revoke the application's access through their Google Account's third-party connections/security settings, and may disable the backup client on the VPS. If access is revoked, automated backups and restores that depend on the connection will stop.

7. Google API Limited Use

The application's use of information received from Google APIs is intended to comply with the Google API Services User Data Policy, including its Limited Use requirements. Data is used only to provide the backup functionality described above.

8. Changes and contact

Material changes to the app's data access or handling will require an update to this policy. For questions, use the owner support contact identified on the application's Google OAuth consent screen. Do not submit credentials or sensitive backup data to a public GitHub issue.
